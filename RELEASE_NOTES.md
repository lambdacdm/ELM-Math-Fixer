# ELM Math Fixer v1.3.12

## What's New since v1.3.11

### UI polish
- **Fixer label now matches ELM's native font** (v1.3.12): the `Fixer` switch label copies `fontFamily` / `fontSize` / `fontWeight` / `lineHeight` / `letterSpacing` from the leftmost native top-bar control (e.g. `Request an ELM API Key`), so the typography is visually identical. No layout, color, spacing, or interaction was changed — the existing stylesheet remains as the hidden-state fallback and is overridden by the inline font only when the label is visible (docked).
